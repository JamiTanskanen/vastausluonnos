# Kolmen minuutin demo

Järjestys on tärkeä: aloita siitä mitä se kieltäytyy tekemästä, älä siitä mitä
se osaa. Onnistunut vastaus ei erotu, kieltäytyminen erottuu.

**0:00 — Kehys, yksi lause.**
"Tämä valmistelee vastausluonnoksia julkiseen tukipostilaatikkoon. Se ei lähetä
mitään, ja se saa sanoa vain sellaista, minkä voi osoittaa teidän omalta
sivultanne."

**0:20 — Avaa `Tarjouspyyntö: 500 yritystä + rajapinta`.**
Luonnosta ei ole. Sen sijaan kahdeksan kysymystä ihmiselle: erähinta, rajapinta,
konesalin sijainti. "Näihin ei ole julkista vastausta, joten se ei keksi
sellaista. Tämä on tuotteen paras hetki, ei sen huonoin."

**0:50 — Avaa `Luokitus on väärä – pyydän rahat takaisin`.**
Luonnos selittää asteikkojen eron ja siteeraa teidän FAQ:tanne. Se ei myönnä
virhettä eikä lupaa hyvitystä. Alla lukee: "Myönnetäänkö hyvitys? Ehdot eivät
velvoita siihen — päätös on sinun."
"Tyyliä matkiva assistentti kirjoittaisi tähän lämpimästi 'hyvitämme
luonnollisesti'. Se kuulostaa teiltä ja sitoo teidät."

**1:30 — Osoita oikeaa laitaa: lähteet.**
Jokainen numero luonnoksessa vie riviin, jossa on julkinen URL ja hakuaika.
"En ole käyttänyt teidän dataanne. Tämä on teidän oma sivustonne."

**1:50 — Käännä kytkin `simuloi hintakoe päällä` ja avaa `Hinnat ja jatkuva käyttö`.**
Sama viesti, eri kanta: hinta ei ole enää yksikäsitteinen.
"Teillä on tuotannossa A/B-hintakoneisto `pricing.json`issa. Koe on nyt pois
päältä. Kun se kytketään päälle, assistentti joka opetteli hinnan ulkoa alkaa
vastata väärin 80 %:lle kysyjistä. Siksi hinta ei ole tietopohjassa, vaan
haetaan joka luonnokselle erikseen."

**2:20 — Terminaali: `npm run portti`.**
Kaksi lukua: keksittyjä väitteitä 0, sellaisenaan lähetyskelpoisia N/12.
"Toinen luku on tässä yhtä tärkeä kuin ensimmäinen. Järjestelmä, joka eskaloi
kaiken, ei keksi koskaan mitään — ja on hyödytön."

**2:40 — `npm run gmail -- vastaa`, näytä Gmail.**
Luonnos ilmestyy Luonnokset-kansioon, oikeaan ketjuun.
"Yksi kirjoitusoperaatio: APPEND. Lähetystoimintoa ei ole olemassa."

**Jos aikaa jää:** oikea saapunut posti — uutiskirjeet menevät luokkaan
"ei luonnosta". Se ratkaisee mitä tällainen maksaa käytössä.
